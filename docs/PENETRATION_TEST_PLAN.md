# خطة اختبار الاختراق المستقل

معرّف الوثيقة: `MCIAS-SEC-001` · الإصدار: 1.0 · الحالة: مسودة للمراجعة · اللغة: العربية

[English version](PENETRATION_TEST_PLAN_EN.md) · [فهرس الحزمة](ACCEPTANCE_PACK_INDEX.md)

## الحالة والتفويض

`NOT_EXECUTED` — هذه خطة، وليست نتيجة فحص أو شهادة أمنية. لا يبدأ أي اختبار نشط قبل توقيع الجهة على [النطاق](PENETRATION_TEST_SCOPE.md)، هوية الفاحص المستقل، عناوين الأهداف، نافذة التنفيذ وقواعد الاشتباك. لا يشمل هذا التكليف تنفيذ هجمات على أنظمة خارجية.

## التنفيذ والأدوار

1. مالك النظام يجمّد SHA والنسخ والبنية وعناوين الاختبار؛ مسؤول البيانات يجيز بيانات اصطناعية فقط في البداية.
2. فريق مستقل يراجع الشيفرة والإعدادات ومخطط الصلاحيات وأدلة CI دون اعتبارها إثبات أمن نهائيًا.
3. يمنح مشغل البيئة حسابات اختبار محدودة ومؤسستين اختباريتين، مع مرجع موثق للصلاحيات المتوقعة. لا تُسلّم مفاتيح التوقيع أو فك التشفير للفاحص.
4. يبدأ الفحص المحدود وفق PT-01 إلى PT-15؛ تُراقب الأخطاء والأحمال دون تسجيل حقول طبية أو رموز جلسات.
5. عند تجاوز النطاق أو ظهور بيانات حقيقية أو فقد سلامة السجلات، يتوقف الاختبار فورًا وتُحفظ أدلة منقحة ويُبلغ اتصال الحوادث المسمى في التفويض.
6. تسجل النتائج في تقرير مستقل، تُصلح على SHA جديد، ثم يعيد الفاحص التحقق. اعتماد التشغيل يتطلب توقيع الجهة ولا ينتج تلقائيًا عن نجاح الفحص.

## المنهج والأدلة

لكل اختبار: PT-ID، SHA، الهدف، وقت UTC، الحساب ودوره دون أسراره، التوقع، الخطوات القابلة للتكرار، النتيجة، ودليل منقح مع SHA-256. تربط الثغرات بـ CWE أو OWASP حيث ينطبق؛ لا تُعلن مطابقة معيار أو شهادة لم تُراجع.

تحدد الشدة وفق قابلية الاستغلال وتأثير الخصوصية والفصل المؤسسي وسلامة المال، مع تبرير وCVSS عند مناسبته. تحفظ الأدلة مشفرة محليًا، بمجلدات خاصة ووصول محدود ومدة احتفاظ توقعها الجهة. لا تُرفع بيانات طبية أو HAR يحوي أسرارًا إلى GitHub أو خدمة عامة.

## الإغلاق

لا قبول مع ثغرة حرجة أو عالية غير معالجة. قبول المخاطر الأقل يحتاج مالكًا مفوضًا وتاريخ انتهاء وتعويضات موثقة وإعادة اختبار. تسجل الوظائف غير المتاحة `BLOCKED`، ولا توصف بأنها اجتازت الاختبار. يظل تنفيذ G5 الإنتاجي، والتطهير الآلي وسجل legal holds خارج القدرات الحالية حتى تطويرها واعتمادها.

حقول التقرير النهائي: التفويض والنطاق؛ المنهج وحدوده؛ نتائج PT كافة؛ سجل الثغرات والمالك والإصلاح؛ SHA إعادة الاختبار؛ المخاطر المتبقية؛ توصية الفاحص؛ توقيع الجهة. كل هذه الحقول الآن `NOT_RECORDED / NOT_SIGNED`.
