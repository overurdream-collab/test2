# قائمة تحقق اختبار اللابتوب

معرّف الوثيقة: `MCIAS-LAP-004` · الإصدار: 1.0 · التاريخ: 2026-10-11 · الحالة: قائمة فارغة للتنفيذ المصرح

[English](LAPTOP_TEST_CHECKLIST_EN.md) · [الخطة](LAPTOP_TEST_PLAN.md) · [Runbook](LAPTOP_RUNBOOK.md) · [التقرير](LAPTOP_TEST_REPORT.md)

## طريقة الاستخدام

علامة [x] تعني أن الحالة نُفذت ووُثقت أو روجع حد نطاقها، ولا تعني PASS وحدها. لكل معرّف سجل النتيجة والدليل ووقت UTC في التقرير. هذه القائمة لا تمنح إذن تنفيذ؛ الموافقة الحالية إعداد وثائق فقط. اقرأ معايير التوقف والدمج في الخطة قبل البدء.

## قبل التنفيذ

- [ ] موافقة المستخدم تشمل نطاق التشغيل والتهيئة والكتابة الاختبارية والملفات المستخدمة؛ مرجعها مسجل.
- [ ] المشغّل والمراجع والجهاز وجولة الاختبار محددون.
- [ ] لا إدخال بيانات حقيقية أو نقل مفاتيح جهاز آخر.
- [ ] قاعدة وvolumes مخصصة، والتثبيت القائم إن وجد راجعه المالك؛ لا حذف أو reset.
- [ ] الفرع وSHA مثبتان؛ لا تعديل/تحديث/push/دمج خلال الجولة دون موافقة جديدة.
- [ ] مسار NTFS محلي، وDocker Desktop Linux/WSL2 جاهز، والوقت والهاتف متزامنان.
- [ ] إعدادات الذاكرة والمساحة الفعلية مسجلة؛ لا افتراض SLA.
- [ ] الدليل المحلي محمي، والتسجيل/مشاركة الشاشة متوقفان عند التعامل مع Credentials.

## إغلاق الجولة

- [ ] كل الحالات الأساسية لها نتيجة فعلية ودليل؛ الناقص NOT_EXECUTED أو BLOCKED، لا PASS.
- [ ] مصدر demo ونتائج API واللابتوب وCI منفصلة؛ لا جمع أعداد اختبارات متداخلة.
- [ ] كل عيب وتحذير وskipped وإعادة اختبار مسجلة؛ العيوب المانعة مغلقة بدليل.
- [ ] الأدلة منقحة من كلمات المرور وTOTP وtokens و.env وبيانات طبية؛ لا raw logs منشورة.
- [ ] الأعداد والمراجع قبل/بعد restart متطابقة؛ لا حذف volumes ولا تجديد مفاتيح.
- [ ] المراجع أكمل التقرير والتوصية؛ حالة القرار HOLD ما دام شرط أساسي غير مستوفى.
- [ ] موافقة رفع الفرع/CI وموافقة الدمج منفصلتان ومسجلتان قبل الإجراء.
- [ ] نجاح التجربة لم يُحوّل إلى قبول مؤسسي أو تصريح بيانات حقيقية.
