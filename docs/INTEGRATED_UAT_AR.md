# خطة اختبار قبول النسخة المجمعة

الحالة: خطة جاهزة للتنفيذ الخارجي؛ لم تُوقّع أو تُعتمد مؤسسيًا.
تستخدم بيانات اصطناعية، ولا تُرفع إليها ملفات مرضى حقيقية.

| الدور | السيناريو | النتيجة المطلوبة |
|---|---|---|
| مسؤول النظام | دخول ببيانات صحيحة دون رمز MFA، ثم برمز صحيح، ثم إعادة استخدام الرمز | رفض الدخول الأول وإعادة الاستخدام، وقبول الدخول الصحيح |
| مسؤول الاستيعاب | رفع CSV/Excel صحيح، رفعه ثانية، ثم ملف تالف | بصمة مصدر موثقة، كشف التكرار، حجر الملف التالف وحفظ الأصل المشفر |
| قارئ الاستيعاب | طلب حقول مصدر دون إذن كل حقل | رفض الطلب دون تسريب قيم؛ المراقبة العامة لا تمنح وصولًا طبيًا |
| موظف المطالبات | تجهيز دفعة واستيرادها واستئنافها وربط الدليل | لا تكرار للمطالبات، محفوظة الأعمدة الأصلية، منع استيراد مصدر محجور |
| المدقق | فتح دليل لقطة G5 اصطناعية موثقة | عرض القيم العشرية وثمانية أصناف وكل مصدر؛ لا زر تشغيل تدقيق إنتاجي |
| مُقدّم الاقتراح | محاولة الموافقة أو الرفض الذاتي، بما فيها بعد تعليق مراجع آخر | رفض من الخادم دون إنشاء حدث قرار |
| المراجع المستقل | اعتماد مقترح قابل للاعتماد ثم فتح التقرير | نتيجة معتمدة موثقة؛ القيم مطابقة للقطة المحرك |
| مقدم الاعتراض | اعتراض دون دليل ثم بدليل صالح وطلب إعادة تدقيق | رفض الأول، تسجيل الثاني مع سلسلة الأحداث وبقاء التقرير السابق ثابتًا |
| مستخدم تنفيذي | اختيار تقرير وعملة وفحص التفاصيل وتنزيل تصدير مصرح | قيم التقرير الثابت دون خلط العملات؛ منع تصدير الأصل دون إذن حقوله |
| مستخدم مؤسسة أخرى | طلب مطالبة أو دليل أو حالة مؤسسة أخرى | رفض من الخادم؛ لا نقل للسياق المؤسسي |
| جميع الأدوار | انتهاء الجلسة/الخروج/تحديث الصفحة | إزالة البيانات المحمية وإعادة الدخول؛ لا توكن في localStorage/sessionStorage |
| مستخدم عربي/إنجليزي | لوحة مفاتيح، قارئ شاشة، هاتف/لوحي، الوضعان | اتجاه وترتيب صحيحان، تركيز واضح، قراءة الجداول دون تجاوز عرض التطبيق |
| المشغل | فحص TLS والصلاحيات ونسخ احتياطي واستعادة على قاعدة منفصلة | أدلة محلية كاملة، تطابق بصمات الملفات والبيانات، وخطة رجوع مجرّبة |

لكل حالة يسجل المختبر: SHA النسخة، إعداد البيئة غير السري، الزمن، النتيجة،
رابط الدليل، العيب إن وجد، اسم المراجع. تُحفظ الأدلة الطبية إن استُخدمت لاحقًا
داخل المؤسسة فقط. نجاح الاختبار الآلي لا يوقّع هذه القائمة.

لقطة G5 المستخدمة في الاختبار الآلي ينتجها محرك Python في تجهيز اصطناعي خاص
بقاعدة `_e2e`؛ لا تعني وجود API تنفيذ إنتاجي أو سياسة مالية معتمدة.

لا يُنقل اعتماد أي بوابة إلى ACCEPTED إلا وفق عقد القبول وتوقيع المخول.
