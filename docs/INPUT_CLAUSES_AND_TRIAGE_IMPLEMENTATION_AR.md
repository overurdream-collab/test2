# MCIAS — تنفيذ سجل بنود المدخلات والتصنيف الرباعي

**الحالة:** تطوير هندسي تجريبي في فرع مستقل، لا دمج ولا قبول إنتاجي.

أنشئ سجل بنود تاريخي متعدد الأقسام (العقود، مقدمو الخدمة، التحمل، الفئات، الاستثناءات، الموافقات والتعرفة الخاصة بكل مقدم خدمة) مع جداول إصدارات وأحداث اعتماد/إغلاق غير قابلة للحذف، وواجهة عربية للاستعراض ورفع ملف وإنشاء مسودة وإصدار بديل. توجد واجهة API للبحث حسب تاريخ الخدمة.

أضيفت أربعة صادرات CSV لتصنيف مطالبات دفعة إلى REJECTED_RULE_CERTAIN أو ACCEPTED_RULES أو MISSING_ATTACHMENTS أو HUMAN_REVIEW من لقطات G5 الموجودة، والنتيجة **تدقيقية استشارية وليست رفض صرف نهائي**. لا تكفي حالة hold لرفض قطعي.

**حدود معروفة:** لا يوجد استخراج AI تلقائي معتمد للعقود من ملف PDF بعد رفعه؛ الرفع يستخدم خدمة الاستيراد الموجودة. سجل النقاط الجديد لا يغير بعد قواعد G3 أو G5 المالية المعتمدة؛ يجب تنفيذ الربط والتحقق مع سياسات المؤسسة قبل قبول التكامل. كذلك تفعيل البنود الإنتاجي معطل حتى التفويض والتحقق الأمني المؤسسي، وتعديلات الأثر الرجعي تتطلب مسار مراجعة مستقلًا. جميع بوابات G0–G9 مفتوحة.

يجب إجراء اختبارات Python وPostgreSQL وواجهات المتصفح والهوية والتواريخ والتصنيف على SHA هذا الفرع قبل دمجه.
