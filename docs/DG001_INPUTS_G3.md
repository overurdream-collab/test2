## العقد المعتمد ومصدر الأسماء

المصدر الفعلي: `docs/CAI01_EXCEL_TO_G4_SOURCE_CONTRACT_AR.md`، القسم 9، توجيه المالك 2026-10-21. ليست الأسماء استنتاجًا من أسماء الجداول:

| رمز العائلة | المرجع المطلوب في العقد | المتاح وما ينقص |
| --- | --- | --- |
| beneficiary | هوية المستفيد وعضوية الموظف/العائلة وفئة/تغطية كل فرد وتواريخها | اشتراك وفئة مؤرخان؛ لا إصدار/اعتماد/اكتمال لعلاقات الأسرة وتاريخ التغطية |
| contract | العقود المعتمدة وشروط مقدم الخدمة والاستثناءات | إصدار عقد مؤرخ ومعتمد؛ الشروط والاستثناءات الكاملة غير ممثلة |
| tariff | تعرفة المقدم/العقد/الفئة/التاريخ | تعرفة خدمة مرتبطة بإصدار العقد؛ نطاق الفئة غير ممثل |
| policy | السياسات الطبية والإدارية والمالية والتفويض | تفويض السياسة المالية الموقع القائم؛ لا مصدر شامل ولا تاريخ سريان للسياسات الطبية والإدارية |
| caps | سقوف المنافع والاستهلاك التراكمي | سياسة مالية قائمة؛ لا سجل استهلاك كامل موثوق |
| history | المطالبات/الصرف التاريخي وسياق التكرار والأدوية المزمنة | مراجع مطالبات سابقة محدودة؛ لا شهادة اكتمال للصرف أو السياق السريري |

`applicable_reference_snapshots(db, claim, policy=None)` يعيد ست شهادات JSON فقط من الخدمة القائمة، دون كتابة/Commit أو مخطط موازٍ. لكل شهادة `family,label,reference_type,reference_id,version,organization_id,service_date,effective_from,effective_until,approved,complete,lookup_complete,lookup_status,source_evidence,gaps`. المصدر يتضمن UUID المصدر والتفويض وSHA-256 دون نص المستند أو هوية المريض. المفاتيح غير الموجودة تبقى null، ولا تُختلق نسخة.

`lookup_complete` يثبت نطاق بحث أصلي محدود فقط، مثل عقد/خدمة/عملة أو تطابق تفويض السياسة الموقع؛ `complete` يخص كامل عائلة المرجع المطلوبة. كل العائلات الحالية تبقى `complete=false` بسبب النواقص أعلاه. لا يستطيع G5 تحويل نجاح بحث محدود إلى قبول شامل.

الاختيار بتاريخ الخدمة بنطاق نصف مفتوح `[effective_from,effective_until)` قبل اختيار الإصدار؛ تعدد العقود المعتمدة الفعالة تعارض. إثبات عقد/تعرفة موثوق يتطلب التفويض نفسه والمؤسسة ومصدر SHA صالحًا والتحقق عبر `verify_production_approval` من سجل المفاتيح الخارجي الحالي، حتى في التجربة؛ علم `approved` وحده لا يكفي. تفويض السياسة يعاد التحقق منه عبر السجل الموقع القائم. لا يستنتج غياب المستفيد أو عدم وجود مطالبات سابقة عدم الأهلية أو استهلاكًا صفريًا أو احتيالًا.
