# نطاق اختبار الاختراق وقواعد الاشتباك

معرّف الوثيقة: `MCIAS-SEC-002` · الإصدار: 1.0 · الحالة: مسودة للمراجعة · اللغة: العربية

[English version](PENETRATION_TEST_SCOPE_EN.md) · [فهرس الحزمة](ACCEPTANCE_PACK_INDEX.md)

## نموذج التفويض الإلزامي

الحالة `NOT_SIGNED`. تُملأ قبل التنفيذ: الجهة والمالك؛ الفاحص المستقل؛ SHA؛ أسماء DNS وعناوين IP والمنافذ المسموحة؛ تاريخ UTC للبداية والنهاية؛ الحسابات والصلاحيات؛ سقف الطلبات والتوازي؛ اتصال الطوارئ وقناة الإبلاغ؛ خطة العودة والاستعادة؛ سياسة الأدلة؛ توقيع مفوض الجهة والفاحص.

يشمل النطاق فقط النسخة المجمدة من FastAPI والواجهتين وقاعدة PostgreSQL وتخزين المصادر المشفر والأرشفة والوكيل TLS المحددة أعلاه. الفصل المؤسسي الحالي يعتمد تثبيتًا وقاعدة وتخزينًا مستقلًا لكل جهة، مع تحقق organization_id في الخدمات؛ لا يُفترض وجود RLS شامل. تحدد الجهة إن كان Redis أو S3 أو OCR أو إضافات أخرى موجودة فعلًا؛ لا يُختبر مكوّن غير منشور.

## المسموح والمحظور

المسموح بعد التوقيع: قراءة إعدادات منقحة، فحص TLS والرؤوس، طلبات محدودة ببيانات اصطناعية، اختبارات رفض الصلاحيات، وتعديل سجلات اختبار قابلة للاستعادة عندما ينص النطاق عليها. تحدد حدود الحمل مسبقًا؛ اختبار الحصص ليس تفويضًا بحجب الخدمة. login/logout مستثنيان من الحصص العامة، لكن قفل الدخول مستقل ويجب احتساب أثره.

المحظور دون تفويض إضافي محدد: استهداف الإنتاج، قراءة بيانات حقيقية، فحص شبكات الجهة خارج الأهداف، الهندسة الاجتماعية، إسقاط قواعد البيانات أو تعطيل triggers، سرقة مفاتيح، تحوير لقطات مالية، تنفيذ شيفرة/SQL عشوائية، إخراج بيانات خارج الموقع، واختبارات ضغط أو fuzzing مدمرة. لا يبدأ نشاط خارجي أو SSRF خارج وجهات مختبر مصرح بها.

لا توجد API إنتاجية لتنفيذ تدقيق G5، ولا CRUD شامل للمستخدمين/المؤسسات أو تطهير آلي بعد سبع سنوات؛ تسجل هذه فجوات ولا تُخترع اختبارات نجاح لها. AI استشاري، ولا يجوز أن يتحول إلى قرار مالي/طبي تلقائي.

مقياس القبول: لا ثغرات حرجة/عالية مفتوحة، نتائج موثقة لكل عنصر متاح وإعادة اختبار مستقلة. توقيع الأمن لا يعوض توقيع السياسات أو UAT أو قبول G1–G9.
