# خطاب إحالة حزمة السياسات للاعتماد

معرّف الوثيقة: `MCIAS-POL-002` · الإصدار: 1.0 · الحالة: مسودة للمراجعة · اللغة: العربية

[English version](COVER_LETTER_EN.md) · [فهرس الحزمة](../ACCEPTANCE_PACK_INDEX.md)

## إلى الجهة المخولة

إلى: رئيس الجهة/المخول القانوني — **غير محدد**. من: مسؤول المشروع — **غير محدد**. المؤسسة والتاريخ ورقم الإحالة: **غير مسجلة**.

الموضوع: مراجعة واعتماد القرارات FIN-ADR-001…FIN-ADR-013 قبل تشغيل السياسات المالية ببيانات حقيقية.

نحيل [حزمة السياسات](POLICY_PACK.md) و[متطلبات الجهة](CLIENT_REQUIREMENTS.md) للمراجعة. النسخة الهندسية موجودة على main؛ يجب تثبيت SHA كامل عند التسليم. نجاح الاختبارات الاصطناعية لا يعني قبول G0–G9، ولا تفويض صرف أو رفض علاج أو اعتماد فترة احتفاظ.

## المطلوب من الجهة

- تعيين مالك مالي ومراجع مستقل ومخول توقيع ومسؤول خصوصية وتشغيل.
- إصدار قرار منفصل لكل ADR: قبول البديل، تعديله، أو رفضه مع السبب؛ لا اعتماد جماعي مبهم.
- توفير سياسة مالية موقعة، أمثلة حساب مرجعية، عقود وملحقات وتعريفات ومستفيدين مصرح بها.
- تحديد نطاق التفويض ومدته ومبالغه وصلاحياته والإلغاء والتجديد، وتقييم آليات التوقيع الثلاث المبينة في الحزمة.
- البت في اقتراح 7 سنوات وبداية المدة والوقف القانوني؛ يبقى الحذف معطلًا.
- الاتفاق على حجم العمل وSLA وRPO/RTO ونطاق UAT واختبار اختراق مستقل.
