# سيناريوهات القبول المؤسسي

معرّف الوثيقة: `MCIAS-UAT-002` · الإصدار: 1.0 · الحالة: مسودة للمراجعة · اللغة: العربية

[English version](UAT_SCENARIOS_EN.md) · [فهرس الحزمة](ACCEPTANCE_PACK_INDEX.md)

## كيفية استخدام السيناريوهات

كل حالة أدناه تبدأ **NOT_EXECUTED**، باستثناء UAT-25 **BLOCKED** بسبب غياب آلية تشغيل G5 إنتاجية. تحفظ نتيجة كل تشغيل منفصلة عن الخطة. سجل العينات والبصمات والوقت والنسخة والدور والدليل والعيب والمراجع في قالب التقرير. كل مصدر واسم حساب في الاختبار اصطناعي؛ يُتبع إذن مستقل عند استخدام نطاق حقيقي لاحقًا.

يراجع المخول أن الرفض الصحيح يُعد نجاحًا لحالة أمنية وأن `held` ليس رفض علاج. تطبيق كل الحالة عبر API حيث موجود؛ شاشة غير متاحة لا تُختبر بزر افتراضي. تظل الأدلة الأصلية داخل المؤسسة.
